## 硬盘电源管理控制板

### 项目定位

基于 FnOS 面向多盘位 NAS 场景，通过**硬件供电控制 + 系统级挂载管理**解决闲置硬盘常驻带来的持续功耗与盘体损耗问题：按需通电、闲置卸载断电，将低频使用的硬盘纳入自动化的冷存储调度。

### 系统构成

| 层 | 组成 | 说明 |
|---|---|---|
| 硬件 | 控制板 | 板载蓝牙模组，**硬盘供电接口 ×4**，独立控制每路供电回路通断；预留 **12V 两线风扇接口 ×2** |
| 固件 | ESP32-C3 | BLE 协议栈 + 供电/风扇 I/O 控制 |
| 上位机 | fnOS 应用包（.fpk） | BLE 连接管理、指令封装、挂载/卸载与风扇调速策略 |

### 核心功能

**1. 硬盘电源管理（4 路独立）**

- 按需通电：收到访问需求时下发上电指令，盘就绪后自动挂载，立即可用
- 闲置断电：长时间未访问时按策略（自动超时或手动）执行 `umount` 卸载，再切断硬盘供电
- 4 路供电独立控制、互不干扰；系统关键盘可加锁，禁止误卸载/误断电
- 配合 `hdparm` 等盘体级电源管理命令，与硬件断电形成双层控制

**2. 温控风扇**

- 12V 两线风扇接口 ×2
- 温度源可配置：指定任意系统温度传感器或 SMART 盘温（`smartctl`/`nvme` 读取）作为调速依据
- 温度升高自动提升转速，实现按温动态调速

**3. 状态监控**

- 实时展示各盘供电/挂载状态、风扇转速、温度
- 历史趋势记录，支持回溯

### 硬件冗余设计

- **每路硬盘供电均配备独立硬件供电切换按钮**：蓝牙未连接、APP 未安装或任何故障导致无法通过软件切换时，可直接拨动硬件按钮手动切换该路供电，保证硬盘在极端情况下仍可人工接管
- 软件控制与硬件按钮互为备份，供电管理不依赖单一通道

### 权限与安全

- 安装时自动配置 `mount`/`umount`/`hdparm` 的 sudo 白名单与温度读取 setuid，普通用户即可完成系统级操作，无需手动授权
- BLE 链路带心跳/超时机制，连接异常时进入安全状态，避免误断电
